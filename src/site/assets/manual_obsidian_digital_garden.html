5. Listas

Lista simples

- Item
- Item
  - Subitem
  - Subitem

Também é possível usar * ou +:

* Item

+ Item

Lista numerada

1. Primeiro item
2. Segundo item
3. Terceiro item

Também funciona com parênteses:

1) Primeiro item
2) Segundo item
3) Terceiro item

Lista de tarefas

- [ ] Tarefa pendente
- [x] Tarefa concluída

Também é possível usar outros caracteres dentro dos colchetes:

- [?] Em dúvida
- [-] Cancelada
- [>] Adiada

13. Callouts

Callouts são caixas visuais de destaque no Obsidian.

Estrutura básica

> Conteúdo do callout.

Callout com título personalizado

> [!tip] Dica importante
> Conteúdo do callout.

Callout recolhível aberto

> [!info]+ Detalhes
> Conteúdo visível inicialmente.

Callout recolhível fechado

> [!info]- Detalhes
> Conteúdo oculto inicialmente.

Tipos principais de callout

TipoSintaxe
Nota[!note]
Resumo[!abstract]
Informação[!info]
Tarefa[!todo]
Dica[!tip]
Sucesso[!success]
Pergunta[!question]

Falha[!failure]

Citação[!quote]

20. Mermaid: diagramas

Mermaid permite criar diagramas com texto.

Fluxograma

```mermaid
flowchart TD
A[Início] --> B[Processo]
B --> C[Fim]
```

Diagrama de sequência

```mermaid
sequenceDiagram
João->>Maria: Aprova?
Maria->>João: Sim
```

Diagrama de classe

```mermaid
classDiagram
ClasseA <|-- ClasseB
ClasseA : +atributo
ClasseA : +metodo()
```

Diagrama ER

```mermaid
erDiagram
CLIENTE ||--o{ PEDIDO : faz
PEDIDO ||--|{ ITEM : possui
```

Gantt

```mermaid
gantt
title Cronograma
dateFormat  YYYY-MM-DD
section Projeto
Planejamento :a1, 2026-06-01, 7d
Execução     :a2, after a1, 14d
```

Pizza

```mermaid
pie
title Distribuição
"Concluído" : 60
"Pendente" : 40
```

21. Frontmatter

Frontmatter é um bloco YAML no início da nota, usado para metadados.

---
title: Projeto Férias
aliases:
  - Ferias
  - Planejamento de férias
tags:
  - projeto
  - ferias
created: 2026-06-08
updated: 2026-06-08
cssclasses:
  - dashboard
---

Campos comuns

CampoUso
titleTítulo da nota
aliasesApelidos da nota
tagsTags da nota
createdData de criação
updatedData de atualização
cssclassesClasses CSS personalizadas
dateData relacionada à nota
statusStatus do item
typeTipo da nota

25. Escapar caracteres

Use \ antes de caracteres especiais para exibi-los literalmente.

Quero mostrarDigite
*texto*\*texto\*
_texto_\_texto\_
#tag\#tag
`código`\`código\`
~texto~\~texto\~
1. item sem virar lista1\. item
[[Nota]] sem virar link\[\[Nota\]\]
![[Nota]] sem virar embed!\[\[Nota\]\]
> citação sem virar citação\> citação
$fórmula$ sem virar fórmula\$fórmula\$

26. Query blocks

Query blocks exibem resultados de busca dentro da nota.

Buscar tag

```query
tag:#projeto
```

Buscar pasta

```query
path:"Projetos"
```

Buscar palavra

```query
ferias
```
